# Suplementos Spartans · material de Instagram

Todo el material de @spartan_fitness_spa, ordenado por tipo.

| Carpeta | Qué hay |
| --- | --- |
| `Feed/AAAA-MM-DD/` | Carruseles del feed por fecha de publicación |
| `Feed/Catalogo/` | Catálogo completo: portada, una lámina por producto (12) y cómo comprar. Sin precios |
| `Historias/AAAA-MM-DD/` | Historias por fecha, en orden de subida |
| `Historias/Series/` | Series reutilizables (ej. `Creatina/`) |
| `Historias/Fijas/` | Historias que se pueden repetir (stock disponible) |
| `Destacadas/` | Portadas de destacadas e historias fijas "Cómo comprar" y "Cómo te llega" |
| `Fotos/` | Fotos de cada producto 4:5 sobre negro |
| `Reels/Por_subir/` | Reels listos, con la fecha en que toca subirlos en el nombre |
| `Reels/Publicados/` | Reels ya subidos |
| `Reels/banco.md` | Texto (caption) de cada reel, listo para copiar |
| `Robot/` | Robot gratis para publicar (pendiente de configurar) |
| `kit/` | Taller de diseño: scripts, fuentes, íconos e imágenes recortadas |

Archivos de la raíz: `CLAUDE.md` (reglas y guía de contenido), `registro.md` (lo publicado), este `README.md`.
